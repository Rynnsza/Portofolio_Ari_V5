# Portofolio Ari V5 🚀

Website portofolio pribadi versi ke-5 yang dibangun menggunakan ekosistem modern **React.js** (via Vite) dan **Tailwind CSS**. Proyek ini tidak hanya menampilkan informasi profil dan hasil karya (portofolio), tetapi juga dilengkapi dengan fitur interaktif seperti sistem komentar/pesan menggunakan **Supabase**, serta halaman *Dashboard* interaktif.

---

## 🌟 Fitur Utama

- **Desain Modern & Responsif**: UI/UX yang disesuaikan untuk berbagai ukuran layar (mobile, tablet, desktop) menggunakan Tailwind CSS.
- **Single Page Application (SPA)**: Navigasi halaman yang mulus dan cepat menggunakan React Router.
- **Integrasi Database Backend**: Menggunakan **Supabase** untuk menyimpan dan mengelola data dinamis seperti komentar pengunjung atau pesan kontak.
- **Dashboard Admin**: Halaman khusus dashboard untuk memantau data (Proyek, Sertifikat, Komentar pengunjung).
- **Animasi & Efek Visual**: Menampilkan animasi yang interaktif (termasuk dukungan Lottie files/GIF) untuk meningkatkan pengalaman pengguna.

---

## 🛠️ Teknologi yang Digunakan

Proyek ini dibangun di atas *stack* teknologi berikut:

- **Frontend Framework**: [React.js](https://reactjs.org/)
- **Build Tool**: [Vite](https://vitejs.dev/) (Sangat cepat untuk *development* & *bundling*)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Backend as a Service (BaaS)**: [Supabase](https://supabase.com/) (PostgreSQL & API)
- **Deployment**: [Vercel](https://vercel.com/) (Terdapat konfigurasi `vercel.json`)

---

## 📋 Prasyarat Instalasi

Pastikan perangkat Anda sudah terinstal perangkat lunak berikut sebelum menjalankan proyek:

- **Node.js** (Versi 16.x atau lebih baru direkomendasikan)
- **NPM** atau **Yarn** atau **PNPM** (Package manager)
- **Akun Supabase** (Jika Anda ingin mengaktifkan fungsionalitas database/komentar)
